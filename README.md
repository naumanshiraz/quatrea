# Quatréa

Luxury perfume e-commerce experience built with Next.js (App Router), React and TypeScript.

## Run locally

    npm install
    npm run dev

Open http://localhost:3000

## Production build

    npm run build
    npm start

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Go to vercel.com, choose Add New, then Project, and import the repository.
3. Keep the detected Next.js settings and select Deploy.
